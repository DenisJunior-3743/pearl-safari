pearl-safari/
├── index.html          ← Home: hero slideshow, featured cards, map
├── discover.html       ← Discover: filter bar, search, sortable grid
├── attraction.html     ← Detail: dynamic single-page for any attraction
├── about.html          ← About: story, values
├── contact.html        ← Contact: form with validation, office map
├── CLOUDINARY_SETUP.md ← How media sync to Cloudinary works
├── css/
│   └── style.css       ← 24-section design system (900+ lines, fully commented)
├── js/
│   ├── data.json              ← 8 real attractions (Uganda parks/lakes/mountains we have genuine photos for), stats, categories
│   ├── cloudinary-media.json  ← Generated by scripts/sync-cloudinary.mjs — per-attraction Cloudinary URLs
│   ├── components.js          ← Navbar + footer injection (write once → every page)
│   ├── animations.js          ← AOS, counter rollup, parallax, tilt, lightbox, toast
│   ├── map.js                 ← Leaflet interactive Uganda map with custom pins
│   ├── main.js                ← Home page rendering from data.json
│   ├── discover.js            ← Filter + search + sort + URL sync logic
│   └── attraction.js          ← Dynamic detail page (reads ?id= from URL)
├── categories/
│   └── image-resolver.js ← Merges cloudinary-media.json into data.json attractions at runtime
├── scripts/
│   └── sync-cloudinary.mjs ← Uploads media to Cloudinary, regenerates cloudinary-media.json
└── assets/
    └── logo/           ← favicon.svg + logo.png (the only media still served locally)

Note: park photos/videos are no longer stored in this repo — they live in Cloudinary
(cloud name in `.env`) and are fetched at runtime via `js/cloudinary-media.json`.
See CLOUDINARY_SETUP.md before adding or changing media.
